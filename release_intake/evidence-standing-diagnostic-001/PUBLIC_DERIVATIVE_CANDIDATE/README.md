## Research object

An assigned synthetic-registry diagnostic examines whether two LLM endpoints distinguish historical factual support, current factual support, and current sandbox permission when they receive different presentations of a peer's historical assessment. Seven synthetic cases compare NO_HANDOFF, PROSE, and STRUCTURED conditions. The task explicitly provides a current source and rules for interpretation.

## Preserved negative predecessor

The first live execution halted after one API request and seven events when a syntactically correct JSON object appeared inside a Markdown JSON fence but the strict parser required bare JSON. No paired cases or scientific comparisons were completed in this predecessor. A separately named, post-observation ingestion repair permitted a single complete JSON fence and was followed by a new full execution; the original event log was neither modified nor counted as a completed run.

## Completed repaired execution

The repaired run recorded 283 internally hash-consistent events, 28 paired cases, 56 generation responses, and 42 second-stage judgments. Each judgment had five exact-match fields. All 210 of 210 evaluated fields matched their bounded synthetic reference values, across all arms. No advantage for structured presentation was observed. The comparison reached a ceiling; no inference of equivalence, larger-population effect, real-world authority, or actual downstream action is warranted.
