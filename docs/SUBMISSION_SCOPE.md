# Publication assembly posture

This repository has been prepared from the candidate `NGAST_2026-10-19_RESEARCH_SUBMISSION_CANDIDATE`. It is intentionally **metadata-first**: public study summaries and exact private-object digests can be examined without exposing raw agent transcripts, credentials, runtime user paths, or rights-uncleared model output.

No live model generation was performed in repository packaging. The Git repository itself does not contain the original event chains, so the initial public commit is **not** an open reproducibility release; say so when citing it. A future disclosure-cleared per-study release may introduce independently hashed public derivatives. Do not rewrite this commit's original research-status claims as retrospective assertions of experimental admission.
